# BBBox Link — Legal & Support

Public-facing legal and support pages for the **BBBox Link** iOS app, hosted as
a static site (e.g. GitHub Pages) so the URLs can be referenced in the App
Store listing.

## Pages

| Page | Purpose | App Store field |
|------|---------|-----------------|
| [`index.html`](index.html) | Privacy Policy | Privacy Policy URL |
| [`support.html`](support.html) | Support page | Support URL |

## About BBBox Link

BBBox Link is the official BarBoards Box technician tool for manufacturing,
QA/QC, troubleshooting, and field service. It connects to BarBoards Box
hardware over Bluetooth Low Energy. The app does not collect personal data,
does not require an account, and does not use any third-party services or
analytics.

- **Bundle ID:** `tv.barboards.bboxlink`
- **Engineered by:** IO-TEQ
- **Brand:** BarBoards

## Hosting

Publish this repository via GitHub Pages (Settings → Pages → Branch: `main`,
Folder: `/`). The resulting URLs:

- Privacy: `https://<org>.github.io/bbbox-link-legal/`
- Support: `https://<org>.github.io/bbbox-link-legal/support.html`

Use those URLs in App Store Connect.
