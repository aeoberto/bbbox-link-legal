BBBox Link – Support

Thank you for using BBBox Link, the official BarBoards Box technician tool for manufacturing, QA/QC, troubleshooting, and field service.

Getting Help

If you experience issues, have questions, or need assistance, contact:

Email: support@io-teq.com

When reporting a problem, please include:

  • App version and build – Scanner toolbar ⚙️ App Settings → About BBBox Link, or toolbar ℹ️ About
  • BarBoards Box UID – Shown as BB_<uid> (for example BB_e072a1aeb804)
  • Firmware and protocol – Visible in About when a device is connected
  • A short description of the issue and steps to reproduce
  • Optional: a support export from the Overview tab (Export support report)

Requirements

  • iPhone or iPad running iOS 16 or later
  • Bluetooth enabled on the iOS device
  • A powered BarBoards Box within Bluetooth range
  • A mobile operator token provisioned for the box (required for operator unlock and technician actions)

Quick Start

  1. Enable Bluetooth on your iOS device.
  2. Open BBBox Link and complete onboarding if prompted.
  3. On the Scanner screen, wait for your box to appear as BB_<uid>.
  4. Tap the device row to connect.
  5. Enter the mobile operator token when the unlock gate appears.
  6. Use Overview, SoMs, Switcher, Tests, and Device Settings as needed.

Common Topics

  • Discovering and connecting to a BarBoards Box over Bluetooth
  • Operator unlock, session expiry, and mobile operator tokens
  • Reading supervisor, SoM, switcher, fan, and power status
  • 3D box model viewer and live telemetry overlays
  • Running hardware tests (relay exercise, fan sweep)
  • Operator actions (route changes, fan control, power cycle)
  • Rotating a mobile operator token (Device Settings → Security)
  • Firmware compatibility and protocol versions
  • Exporting a support report from Overview (Export support report)

Troubleshooting

Bluetooth is off or permission denied

Ensure Bluetooth is on in Control Center or Settings. Grant BBBox Link access in iOS Settings → Privacy & Security → Bluetooth → BBBox Link.

No boxes appear in Scanner

  • Confirm the BarBoards Box is powered and advertising as BB_<uid>.
  • Move closer to the box and tap Rescan.
  • Verify no other app is holding an exclusive connection to the box.

Unlock fails

  • Confirm you are using the correct mobile operator token for that box UID.
  • Operator tokens are separate from Jetson or venue credentials.
  • After a successful unlock, tokens can be stored in Keychain for reuse on this device.

Connection lost or session expired

Return to the device session and use Reconnect, or unlock again if the operator session expired. Enable Auto-reconnect last device in App Settings if you want Scanner to reconnect automatically on your next visit.

Clear saved credentials

App Settings → Security → Clear all saved operator tokens removes all mobile operator tokens from Keychain on this device. Connected sessions are not locked automatically.

Privacy

BBBox Link does not send your data to IO-TEQ or BarBoards servers. See the Privacy Policy for details on Bluetooth access, on-device storage, and optional support exports.

Device Support

BBBox Link works with supported BarBoards Box hardware running compatible firmware. Ensure the unit is powered, within Bluetooth range, and provisioned with a valid mobile operator token for technician access.
