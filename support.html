BBBox Link – Support

Thank you for using BBBox Link, the official BarBoards Box technician tool for manufacturing, QA/QC, troubleshooting, and field service.

Getting Help

If you experience any issues, have questions, or need assistance, please contact:

Email: support@io-teq.com

Please include your app version (Settings → About), the BarBoards Box UID (e.g. BB_e072a1aeb804), and a short description of the issue.

Common Topics

  • Discovering and connecting to a BarBoards Box over Bluetooth
  • Operator unlock and session authentication
  • Reading supervisor, SoM, switcher, fan, and power status
  • Running hardware tests (relay exercise, fan sweep)
  • Operator actions (route changes, fan control, power cycle)
  • Firmware compatibility and protocol versions

Requirements

  • iPhone or iPad running iOS 16 or later
  • Bluetooth enabled on the iOS device
  • A powered BarBoards Box within Bluetooth range

Bluetooth Permission

BBBox Link requires Bluetooth permission to discover and connect to BarBoards Box hardware. If the app cannot find a device, verify Bluetooth is enabled and that BBBox Link has Bluetooth access in iOS Settings → Privacy & Security → Bluetooth.

Device Support

BBBox Link works with supported BarBoards Box hardware. Ensure the unit is powered, within Bluetooth range, and running compatible firmware.
